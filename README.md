# HollowedTreeFix

A rebuilt Hollowed Tree dungeon for [Valheim Cuisine](https://thunderstore.io/c/valheim/p/Xutz/ValheimCuisine/) by Xutz. The dungeon is Xutz's work; this mod replaces only that structure and needs Valheim Cuisine installed.

## What it changes

- The opening on the stump, the exit and the windows are rebuilt.
- Chest loot no longer includes meads.

Loot is rolled when a tree is first generated, so trees already discovered in a world keep their old chests. Everyone on a server should have the mod.
